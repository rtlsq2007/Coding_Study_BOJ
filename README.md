## ✅ 10950 - A+B - 3  
**문제 유형:** 반복문, 입출력  

### 📌 문제 설명  
테스트 케이스 T가 주어지고, 각 줄마다 두 정수 A와 B가 주어진다.  
각 테스트 케이스마다 A+B를 출력하는 문제이다.

### 💡 풀이 설명  
반복문을 사용하여 입력을 받고, 입력받은 값을 즉시 계산하여 출력하는 방식으로 해결했다.  
처음에는 배열에 저장하려 했지만, 이 문제는 저장 없이 바로 처리하는 구조가 더 효율적이라는 것을 알게 되었다.

### 🧠 배운 점  
- 반복문을 활용한 입력 처리  
- 불필요한 배열 사용을 줄이는 사고방식  
- 단순한 구조로 문제를 바라보는 연습  

### ✍ 느낀 점  
문제를 괜히 복잡하게 생각하지 말고, 가장 단순한 해결 방법을 먼저 떠올리는 것이 중요하다고 느꼈다.

## ✅ 15552 - 빠른 A+B  
**문제 유형:** 반복문, 빠른 입출력  

### 📌 문제 설명  
테스트 케이스 T가 매우 크게 주어질 때, 각 줄마다 두 정수를 입력받아 합을 출력하는 문제이다.  
일반적인 입력 방식으로는 시간 초과가 발생할 수 있다.

### 💡 풀이 설명  
기존 A+B 문제와 구조는 동일하지만, 입력 개수가 많기 때문에  
`ios::sync_with_stdio(false);`와 `cin.tie(nullptr);`를 사용하여 입출력 속도를 개선하였다.  
또한 `endl` 대신 `"\n"`을 사용하여 불필요한 flush를 방지하였다.

### 🧠 배운 점  
- C++에서 입출력 속도 최적화 방법  
- sync 해제와 tie 해제의 역할  
- 시간 초과는 로직 문제가 아니라 입출력 문제일 수도 있다는 점  

### ✍ 느낀 점  
단순한 문제처럼 보였지만, 입출력 최적화의 중요성을 배울 수 있었다.

## ✅ 2439 - 별 찍기 - 2  
**문제 유형:** 반복문, 이중 반복문, 출력 패턴

### 📌 문제 설명
정수 N이 주어졌을 때 별(*)을 이용하여 오른쪽 정렬된 삼각형을 출력하는 문제이다.

### 💡 풀이 설명
각 줄마다 출력해야 하는 **공백과 별의 개수 규칙**을 찾아 구현하였다.

- i번째 줄의 공백 개수 → `N - i`
- i번째 줄의 별 개수 → `i`

따라서 한 줄을 출력할 때  
1. 공백을 먼저 출력하고  
2. 별을 출력하도록 구현하여 오른쪽 정렬을 만들었다.

### 🧠 배운 점
- 이중 반복문을 활용한 출력 패턴 구현  
- 공백과 별의 개수를 계산하여 정렬을 만드는 방법  
- 규칙을 찾으면 별 찍기 문제는 구조가 비슷하다는 점

### ✍ 느낀 점
처음에는 공백의 개수를 계산하는 부분이 헷갈렸지만 규칙을 이해하고 나니 별 찍기 문제는 반복문 패턴 문제라는 것을 알게 되었다.

## ✅ 10952 - A+B - 5  
**문제 유형:** 반복문, 종료 조건

### 📌 문제 설명

### 🧠 배운 점

- `break`를 이용한 반복문 종료  
- 입력이 특정 조건일 때 프로그램 흐름을 제어하는 방법

### ✍ 느낀 점
반복문을 사용할 때 종료 조건을 어떻게 설정하는지가 중요하다는 것을 배웠다.

## ✅ 10951 - A+B - 4  
**문제 유형:** 반복문, EOF 입력 처리

### 📌 문제 설명
두 정수 A와 B를 입력받아 합을 출력하는 문제이다.  
입력의 개수는 정해져 있지 않으며 **입력이 끝날 때까지 계속 처리해야 한다.**

### 💡 풀이 설명
입력 개수가 주어지지 않기 때문에  
입력이 정상적으로 들어오는 동안 반복문을 실행하도록 구현하였다.

C++에서는 `cin >> a >> b` 가 성공하는 동안 반복하도록 작성하면  
입력이 끝나는 순간 반복문이 종료된다.

### 🧠 배운 점
- 입력의 개수가 정해지지 않은 경우 처리 방법  
- EOF(End Of File) 기반 반복문 사용  
- 문제마다 입력 종료 방식이 다르다는 점

### ✍ 느낀 점
비슷한 A+B 문제라도 입력 종료 방식이 서로 다르다는 것을 알게 되었고, 문제의 입력 조건을 정확히 읽는 것이 중요하다는 것을 느꼈다.
