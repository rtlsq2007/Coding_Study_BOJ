## ✅ 10950 - A+B - 3  
**문제 유형:** 반복문, 입출력  

### 📌 문제 설명  
테스트 케이스 T가 주어지고, 각 줄마다 두 정수 A와 B가 주어진다.  
각 테스트 케이스마다 A+B를 출력하는 문제이다.

### 💡 풀이 설명  
반복문을 사용하여 입력을 받고, 입력받은 값을 즉시 계산하여 출력하는 방식으로 해결했다.  
처음에는 배열에 저장하려 했지만, 이 문제는 저장 없이 바로 처리하는 구조가 더 효율적이라는 것을 알게 되었다.

### 🧠 배운 점  
- 반복문을 활용한 입력 처리  
- 불필요한 배열 사용을 줄이는 사고방식  
- 단순한 구조로 문제를 바라보는 연습  

### ✍ 느낀 점  
문제를 괜히 복잡하게 생각하지 말고, 가장 단순한 해결 방법을 먼저 떠올리는 것이 중요하다고 느꼈다.

## ✅ 15552 - 빠른 A+B  
**문제 유형:** 반복문, 빠른 입출력  

### 📌 문제 설명  
테스트 케이스 T가 매우 크게 주어질 때, 각 줄마다 두 정수를 입력받아 합을 출력하는 문제이다.  
일반적인 입력 방식으로는 시간 초과가 발생할 수 있다.

### 💡 풀이 설명  
기존 A+B 문제와 구조는 동일하지만, 입력 개수가 많기 때문에  
`ios::sync_with_stdio(false);`와 `cin.tie(nullptr);`를 사용하여 입출력 속도를 개선하였다.  
또한 `endl` 대신 `"\n"`을 사용하여 불필요한 flush를 방지하였다.

### 🧠 배운 점  
- C++에서 입출력 속도 최적화 방법  
- sync 해제와 tie 해제의 역할  
- 시간 초과는 로직 문제가 아니라 입출력 문제일 수도 있다는 점  

### ✍ 느낀 점  
단순한 문제처럼 보였지만, 입출력 최적화의 중요성을 배울 수 있었다.

## ✅ 11021 - A+B - 7  
**문제 유형:** 반복문, 형식 출력  

### 📌 문제 설명  
각 테스트 케이스마다 A+B를 구하되,  
출력 형식을 `Case #x: 결과` 형태로 출력해야 하는 문제이다.

### 💡 풀이 설명  
반복문을 통해 입력을 받고,  
각 줄마다 형식에 맞춰 문자열과 값을 조합하여 출력하였다.  
출력 형식에서 공백 위치가 매우 중요했다.

### 🧠 배운 점  
- 출력 형식을 정확히 맞추는 것의 중요성  
- 문자열과 변수 값을 `<<` 연산자로 연결하는 방법  
- 문제에서 요구하는 형식을 그대로 따르는 습관  

### ✍ 느낀 점  
로직은 간단하지만, 출력 형식 하나 때문에 오답이 날 수 있다는 것을 배웠다.

## ✅ 11022 - A+B - 8  
**문제 유형:** 반복문, 형식 출력  

### 📌 문제 설명  
11021과 유사하지만,  
`Case #x: A + B = 결과` 형식으로 출력해야 한다.

### 💡 풀이 설명  
입력받은 A와 B를 그대로 출력 형식에 포함시켜야 하므로  
변수를 문자열 안에 넣지 않고, `<<` 연산자를 사용하여 순서대로 출력하였다.

### 🧠 배운 점  
- 변수는 따옴표 안에 넣는 것이 아니라, 출력 연산자로 연결해야 한다는 점  
- 문자열과 숫자 출력을 자연스럽게 조합하는 방법  

### ✍ 느낀 점  
출력 문제는 사소해 보이지만, 정확성이 매우 중요하다는 것을 다시 느꼈다.
