# 2️⃣ 10950 - A+B - 3

🔗 [https://www.acmicpc.net/problem/10950](https://www.acmicpc.net/problem/10950)

## 📌 문제 설명

테스트 케이스 T가 주어지고, 각 줄마다 두 정수 A와 B가 주어진다.
각 테스트 케이스마다 A+B를 출력하는 문제이다.

## 💡 풀이 설명

테스트 케이스 수만큼 반복문을 실행하여 입력을 받고,
각 입력에 대해 덧셈 결과를 바로 출력하는 방식으로 해결했다.

처음에는 배열을 사용해 값을 저장한 뒤 출력하려고 했지만,
이 문제는 입력을 받는 즉시 계산해 출력하는 구조가 더 효율적이라는 것을 알게 되었다.

## 🧠 배운 점

* 단순 반복 문제에서는 굳이 배열을 사용할 필요가 없다는 점
* 반복문을 활용한 입력 처리 패턴
* C++에서 변수 초기화의 중요성

## ✍ 느낀 점

문제를 복잡하게 생각하지 않고, 가장 단순한 구조로 접근하는 연습이 필요하다고 느꼈다.

# 3️⃣ 8393 - 합

🔗 [https://www.acmicpc.net/problem/8393](https://www.acmicpc.net/problem/8393)

## 📌 문제 설명

1부터 n까지의 합을 구하는 문제이다.

## 💡 풀이 설명

1부터 n까지 반복문을 돌며 누적 합을 구했다.
반복문의 시작 조건과 종료 조건을 정확하게 설정하는 것이 핵심이었다.

## 🧠 배운 점

* 누적 합 계산 패턴 (`sum += i`)
* 반복문의 범위 설정의 중요성

## ✍ 느낀 점

아주 기본적인 문제지만, 반복문을 정확히 이해하고 있는지 점검하는 좋은 문제였다.

# 4️⃣ 25304 - 영수증

🔗 [https://www.acmicpc.net/problem/25304](https://www.acmicpc.net/problem/25304)

## 📌 문제 설명

총 금액과 각 물건의 가격 및 개수가 주어질 때,
계산한 총합이 실제 총 금액과 일치하는지 확인하는 문제이다.

## 💡 풀이 설명

물건의 개수만큼 반복문을 사용하여
각 물건의 (가격 × 개수)를 누적 합으로 계산하였다.
최종 합계와 처음 주어진 총 금액을 비교하여 일치 여부를 판단했다.

## 🧠 배운 점

* 반복문을 이용한 누적 계산 방식
* 조건문을 통한 값 비교
* 자료형 범위에 대한 고려의 필요성

## ✍ 느낀 점

단순 계산 문제이지만, 변수 초기화와 자료형 선택이 중요하다는 것을 다시 한번 느꼈다.

# 5️⃣ 25314 - 코딩은 체육과목 입니다

🔗 [https://www.acmicpc.net/problem/25314](https://www.acmicpc.net/problem/25314)

## 📌 문제 설명

정수 N이 주어질 때,
N/4 만큼 "long"을 출력하고 마지막에 "int"를 출력하는 문제이다.

## 💡 풀이 설명

정수 N을 4로 나눈 몫만큼 반복문을 실행하여 "long"을 출력하고,
마지막에 "int"를 출력하는 방식으로 해결했다.

## 🧠 배운 점

* 반복문을 활용한 문자열 출력
* 정수 나눗셈의 활용

## ✍ 느낀 점

출력 형식을 정확하게 맞추는 것이 중요하다는 것을 다시 한번 느꼈다.
