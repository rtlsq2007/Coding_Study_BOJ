## ✅ 10950 - A+B - 3  
**문제 유형:** 반복문, 입출력  

### 📌 문제 설명  
테스트 케이스 T가 주어지고, 각 줄마다 두 정수 A와 B가 주어진다.  
각 테스트 케이스마다 A+B를 출력하는 문제이다.

### 💡 풀이 설명  
반복문을 사용하여 입력을 받고, 입력받은 값을 즉시 계산하여 출력하는 방식으로 해결했다.  
처음에는 배열에 저장하려 했지만, 이 문제는 저장 없이 바로 처리하는 구조가 더 효율적이라는 것을 알게 되었다.

### 🧠 배운 점  
- 반복문을 활용한 입력 처리  
- 불필요한 배열 사용을 줄이는 사고방식  
- 단순한 구조로 문제를 바라보는 연습  

### ✍ 느낀 점  
문제를 괜히 복잡하게 생각하지 말고, 가장 단순한 해결 방법을 먼저 떠올리는 것이 중요하다고 느꼈다.

## ✅ 8393 - 합  
**문제 유형:** 반복문, 누적합  

### 📌 문제 설명  
1부터 n까지의 합을 구하는 문제이다.

### 💡 풀이 설명  
1부터 n까지 반복문을 실행하며 누적 합을 계산하였다.

### 🧠 배운 점  
- 누적합 패턴 이해 (`sum += i`)  
- 반복문의 범위 설정 중요성  

### ✍ 느낀 점  
기초적인 문제지만 반복문 개념을 다시 점검할 수 있었다.

## ✅ 25304 - 영수증  
**문제 유형:** 반복문, 조건문  

### 📌 문제 설명  
총 금액과 물건의 가격 및 개수가 주어질 때, 계산한 총합이 실제 총 금액과 일치하는지 확인하는 문제이다.

### 💡 풀이 설명  
각 물건의 가격과 개수를 곱한 값을 누적하여 합계를 구하고, 최종 합과 총 금액을 비교하였다.

### 🧠 배운 점  
- 반복문을 활용한 누적 계산  
- 조건문을 통한 값 비교  
- 자료형 범위에 대한 고려 필요성  

### ✍ 느낀 점  
단순 계산 문제라도 자료형과 변수 초기화는 항상 신경 써야 한다는 것을 느꼈다.
